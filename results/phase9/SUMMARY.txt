WHAT WAS RUN AT EVERY SCALE
  graphs:      canonical v783 thresholded at 5 synapses (1x), then renorm.upscale to
               2x/5x/10x with the recorded geometry (standardised anatomical xyz,
               P(connect)=1/(1+exp((d-R)/T)) fit on the graph itself)
       1x: N=139,255  connections=2,700,513  synapses=34,153,566
       2x: N=278,510  connections=5,187,641  synapses=68,433,997
       5x: N=696,275  connections=13,511,566  synapses=172,021,005
      10x: N=1,392,550  connections=27,891,361  synapses=347,182,855
  dynamics:    synchronous threshold cascade (flyscale.propagation), 8 steps, relative
               threshold fixed at 3.00 x the graph's own mean synapses/connection
  stimulus:    96 classes, each trial seeds 0.0020 x N neurons drawn from a class pool of
               0.0040 x N stimulable neurons (sensory / visual_projection / optic)
  readout:     binary final activation mask over 0.050 x N neurons (fixed seed);
               nearest-centroid / template-matching decoder (analytic, no training)
  statistics:  every threshold-based capability requires accuracy >= threshold AND a
               one-sided exact binomial p<0.05 vs chance; accuracies that clear the
               threshold but not the test are listed separately, never counted
  protocol revision: v3 (superseded revisions kept under results/phase9/
               scales_archive/ and artifacts_archive/, both described in the JSON)
  readout dims: 1x->6963, 2x->13926, 5x->34814, 10x->69628

ERRORS AND THINGS THAT COULD NOT BE MEASURED
  no battery failed at any scale
  not measured: spikes per biological second (the cascade is step-based; no step duration is asserted)
  not measured: an independent power-vs-N exponent (the biological model is linear in N by construction, so it cannot test the energy hypothesis by itself)
  limited by the tested grid (the value is bounded by the protocol, not the network):
    - min_separable_delta: the smallest stimulus distance tested (Delta = 0.05) is already separable at some scales, so the fitted exponent for Delta* is bounded below by the grid, not by the network; use the MI-at-Delta=0.05 column as the censoring-free discrimination measure
    - memory_capacity: capacity is at the top of the tested grid (96 associations) at some scales, so the fitted exponent is a lower bound; the capacity at the stricter 0.99 threshold resolves further
  limited by a measurement ceiling (no headroom left in the metric):
    - stimulus_response_mi_bits: the decoder's information is capped at log2(96) = 6.585 bits by the number of stimulus classes; the 5x and 10x values sit on that cap, so their difference is not a network property
    - generalization_novel_accuracy: at the 1.0 measurement ceiling at every scale: no headroom to detect growth (a harder version of the task would be needed)
    - robustness_accuracy_at_max_neuron_lesion: at the 1.0 measurement ceiling at every scale: no headroom to detect growth (a harder version of the task would be needed)
    - accuracy_at_full_stimulus_difference: at the 1.0 measurement ceiling at every scale: no headroom to detect growth (a harder version of the task would be needed)
    - distinct_pattern_ratio: at the 1.0 measurement ceiling at every scale: no headroom to detect growth (a harder version of the task would be needed)
    - robustness_mi_retention: a retention above 1.0 is estimation noise from 10 test samples per lesion rate, not an improvement; the MI robustness numbers carry that caveat

HOW TO REPRODUCE
  cd ~/Projects/VybFly
  .venv/bin/python scripts/phase9_capability.py --stage all
  stages, in order (each is resumable and writes its own output):
    --stage replicas    # build/cache the 1x-10x graphs under results/phase9/replicas/
    --stage calibrate   # fix the cascade threshold + robustness reference on 1x only
    --stage run --scales 1 2 5 10   # ~1 min / 2 min / 5 min / 11 min on this shared host
    --stage verify      # re-run 1x and compare every capability field
    --stage aggregate   # fit the exponents, write capability.json + SUMMARY.txt
  every protocol number, seed, geometry parameter, fit and error is recorded in
  results/phase9/capability.json; the per-scale response matrices are in
  results/phase9/artifacts/
