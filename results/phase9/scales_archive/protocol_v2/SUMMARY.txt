WHAT WAS RUN AT EVERY SCALE
  graphs:      canonical v783 thresholded at 5 synapses (1x), then renorm.upscale to
               2x/5x/10x with the recorded geometry (standardised anatomical xyz,
               P(connect)=1/(1+exp((d-R)/T)) fit on the graph itself)
       1x: N=139,255  connections=2,700,513  synapses=34,153,566
       2x: N=278,510  connections=5,187,641  synapses=68,433,997
       5x: N=696,275  connections=13,511,566  synapses=172,021,005
      10x: N=1,392,550  connections=27,891,361  synapses=347,182,855
  dynamics:    synchronous threshold cascade (flyscale.propagation), 8 steps, relative
               threshold fixed at 3.00 x the graph's own mean synapses/connection
  stimulus:    96 classes, each trial seeds 0.0020 x N neurons drawn from a class pool of
               0.0040 x N stimulable neurons (sensory / visual_projection / optic)
  readout:     binary final activation mask over 0.050 x N neurons (fixed seed);
               nearest-centroid / template-matching decoder (analytic, no training)
  statistics:  every threshold-based capability requires accuracy >= threshold AND a
               one-sided exact binomial p<0.05 vs chance; accuracies that clear the
               threshold but not the test are listed separately, never counted
  protocol revision: v2 (superseded revisions kept under results/phase9/
               scales_archive/ and artifacts_archive/, both described in the JSON)
  readout dims: 1x->6963, 2x->13926, 5x->34814, 10x->69628
